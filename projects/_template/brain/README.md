# Brain — База знаний

Здесь хранятся карточки людей, идей, конкурентов и организаций.

## Как пользоваться

- **Запомнить человека:** скажи "запомни [имя]" — создастся карточка в brain/
- **Найти:** скажи "кто такой [имя]" — поиск по карточкам
- **Идея:** скажи "запомни идею [описание]"
- **Конкурент:** скажи "запомни конкурента [название]"

## Структура

Карточки создаются по шаблонам из `templates/`:
- `person.md` — человек (клиент, партнёр, конкурент)
- `idea.md` — идея для контента или продукта
- `competitor.md` — конкурент или аналог
- `org.md` — организация или компания
