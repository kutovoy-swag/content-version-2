# Агенты

## Критики

В папке `analytics/critics/` — три критика для оценки контента:

| Критик | Что проверяет |
|--------|--------------|
| **creative-critic** | Креативность, свежесть подачи, оригинальность |
| **sales-critic** | Продающая сила, CTA, мотивация к действию |
| **structure-critic** | Структура, логика, читаемость |

### Как использовать

Скажи "проверь пост" или "критика" — Claude загрузит критиков и даст оценку.

Расширенная библиотека агентов — в `docs/advanced/`.
