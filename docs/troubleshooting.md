# Решение проблем

## Частые вопросы

### Claude Code не запускается

**Проблема:** команда `claude` не найдена.

**Решение:**
1. Убедись что Node.js установлен: `node --version` (нужна 18+)
2. Установи Claude Code: `npm install -g @anthropic-ai/claude-code`
3. Если ошибка прав: `sudo npm install -g @anthropic-ai/claude-code`

### "Скиллы не найдены"

**Проблема:** Claude говорит что не нашёл скиллы при запуске.

**Решение:**
1. Убедись что ты в правильной папке: `cd ~/my-content-factory` (или как назвал)
2. Проверь что `.claude/skills/` не пуста: `ls .claude/skills/`
3. Если пуста — возможно репозиторий не полностью склонирован. Склонируй заново.

### Контент не похож на меня

**Решение:**
1. Скажи `интервью` — перенастроим голос
2. Покажи 2-3 примера своих реальных текстов
3. После каждой генерации говори что нравится/не нравится — система учится

### Claude не помнит мои настройки

**Причина:** каждая сессия Claude Code начинается заново. Но настройки сохраняются в файлах.

**Решение:**
1. Убедись что `brand/` заполнен (проверь `brand/profile.md`)
2. Claude автоматически читает `brand/` при каждом запуске
3. Если файлы пусты — скажи "начать" для повторной настройки
