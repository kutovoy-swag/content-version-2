# Проект: [название]

> Заполни brand/ и начни работать. Скиллы подхватываются автоматически.

## Обязательно загружать

```
brand/profile.md      — кто я
brand/voice-style.md  — как пишу  
brand/audience.md     — кто читает
```

## Как работает

1. Напиши что нужно → Claude подберёт скилл из `.claude/skills/`
2. Загрузит твой голос из `brand/`
3. Проверит `learning/` чтобы не повторять ошибки
4. Сгенерирует контент

## Примеры

- "Напиши 5 постов для Threads"
- "Сценарий для YouTube на тему [...]"
- "Карусель про [...]"
